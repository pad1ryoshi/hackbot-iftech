## O que é um hackbot?

- Hackbot, na definicação atual, é um sistema de *IA Agentic* voltado para segurança ofensiva, capaz de receber um objetivo, planejar ações, executar tarefas de segurança, analisar os resultados e decidir os próximos passos.
